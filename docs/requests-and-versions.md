Every agreement starts as a request and moves through versions until one is approved.

## Capture a request

Choose **New request** on Agreements and fill in **Agreement title**, **Request type**, the **Counterparty** (an existing one or a new one), **Agreement value (AUD)**, the **Responsible person**, **Needed by** and the **Proposed start date**. Start from an approved **Template version** from the Library, or attach a **Draft (PDF or DOCX)**.

Each request type carries the attachments it needs before review:

| Request type | Required attachment |
| --- | --- |
| Supplier | Insurance certificate of currency |
| Customer | Statement of work or schedule |
| Amendment | The signed parent agreement, and a link to it |
| Order form | A link to the agreement it sits under |
| NDA and other | None |

Add more under **Also require (one per line)**. A request cannot go to review while a required attachment is missing, unless the owner or counsel waives it with a reason.

Mark a request restricted to keep it to the owner, counsel, its requester, its responsible person and people you grant access. To everyone else it does not exist.

## Import a signed file

For one agreement signed outside Locket, choose **Import signed file**: the PDF or DOCX, **Where it came from** and its **Source ID**. Locket keeps the original bytes and refuses the same file or source ID twice. For a whole DocuSign archive, see [Move in from DocuSign](/docs/move-in).

## Negotiate in versions

On the agreement's **Versions** tab, add your own revision or the counterparty's markup as a PDF or DOCX. Every original stays exactly as uploaded. **Compare versions** shows any two versions line by line, and **Comments** can quote the passage they are about. When the version is ready, **Submit for review**.

Locket reads the text of DOCX files. For a PDF, paste its text with the upload if you want to compare it or cite it in review.
